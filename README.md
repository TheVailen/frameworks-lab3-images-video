# Лабораторная работа №3 — Извлечение разметки из видео

## Описание

Задача "воровства разметки": извлечение bounding box из размеченного видео,
сохранение в формат COCO и обучение детектора объектов.

## Методы извлечения bbox

### Метод 1 — внешние контуры
Разностная маска + бинаризация + поиск внешних контуров.

### Метод 2 — прямоугольные контуры + NMS (выбран как основной)
Разностная маска + фильтрация по прямоугольности + NMS.

## Метрики извлечения

| Метрика | Значение |
|---|---|
| Precision@IoU0.5 | 0.59 |
| Recall@IoU0.5 | 0.55 |
| Mean IoU matched | 0.74 |

## Модель

Faster R-CNN (ResNet-50 + FPN), предобученная на COCO,
дообучена на извлечённой разметке.
